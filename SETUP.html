第一次連線設定

網頁可以先在本地記錄與下載 TXT。完成以下設定後，才會啟用 Google Drive 自動同步。請自行登入 Google；不需要提供密碼給任何人。

1. 免費啟用 GitHub Pages

  1. 開啟 儲存庫 Pages 設定。
  2. 在 Build and deployment 選擇 Deploy from a branch，分支選 main，資料夾選 / (root)，儲存。
  3. 等待 Pages 完成發布，開啟 工作簿網址。此公開儲存庫可用 GitHub Free，不需付費方案或自訂網域。

2. 建立 Google Cloud 專案及啟用 API

  1. 開啟 Google Cloud Console，建立或選擇你自己的專案。不需為這個設計啟用付費運算服務。
  2. 在 API 和服務 → 程式庫，啟用 Google Drive API 與 Google Picker API。
  3. 在專案資訊記下 Project number（專案編號，純數字），不是文字的 Project ID。

3. 設定 Google Auth Platform / OAuth

  1. 進入 Google Auth Platform（或 API 和服務 → OAuth 同意畫面），填寫應用程式名稱、支援與聯絡信箱。
  2. 個人 Gmail 選外部使用者；若保持測試狀態，把自己的 Google 帳號加入測試使用者。公司 Workspace 帳號可能受管理員政策限制。
  3. 在資料存取新增 https://www.googleapis.com/auth/drive.file。本工具不要求整個 Drive 的廣泛權限。
  4. 建立 OAuth 用戶端，類型選 網頁應用程式。已授權 JavaScript 來源加入 https://desperate972.github.io，不要加專案路徑或結尾斜線。此工具使用彈出式 token flow，不需要設定重新導向 URI。
  5. 複製 Client ID，不要複製 Client Secret。本地測試時可另外加入 http://127.0.0.1:4173。

如果服務商的同意畫面要求驗證或不接受某項網址，請依當下顯示的指示處理；不要為了跳過設定而加入完整 Drive 權限或把機密憑證公開。

4. 建立受限的 Picker API Key

  1. 在相同專案的 API 和服務 → 憑證建立 API 金鑰。
  2. 應用程式限制選「網站／HTTP 參照網址」，只允許 https://desperate972.github.io/*；需要本地測試才加入 http://127.0.0.1:4173/*。
  3. API 限制只允許 Google Picker API。此金鑰用於瀏覽器選擇器，必須限制來源及 API；不要使用其他服務的無限制金鑰。

5. 在工作簿連接資料夾

  1. 回工作簿，開啟「連線設定」，填入 Client ID、受限 API Key、專案編號。目標資料夾已預填。
  2. 儲存後按「連接 Google Drive」，登入有權限的同一個 Google 帳號。
  3. 在 Google 選擇器中選取目標資料夾 1CkO9RaZcvcLXd9yEpHuZ5VSY5vy7Vw0C。選擇資料夾授權不代表將資料夾公開。
  4. 先新增一筆測試工作，確認 Drive 出現 _WaninWorkOutput_data，及日期命名的兩份 TXT，再到 Android Chrome 開啟同網址、設定與連接。

使用時會遇到的狀況

  • 重新開啟網頁或權杖過期後，需要重新按連接。此免費靜態網站不會保存登入權杖或偷偷刷新授權。
  • 資料先保存本地，只有連線及授權有效時才同步。網頁關閉不會在背景持續執行。
  • 自動同步和 TXT 更新失敗時，使用「輸出 TXT」比較時間後重試，或下載到裝置。
  • 手機若只下載一份 TXT，請允許 Chrome 的多檔下載；完整 JSON 備份則只有一份。
  • Google Drive 空間已滿時請釋放空間，並保留本地備份。先使用免費額度即可；本工具不會替你啟用付費方案。
